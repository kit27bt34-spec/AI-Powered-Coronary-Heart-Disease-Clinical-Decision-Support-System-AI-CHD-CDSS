DATASETS USED IN THIS PROJECT:
---------------------------------------------------------------------------------------------------------------------
1. Framingham Heart Study Dataset (framingham.csv)
   - Record Count: 4,241 patient records
   - Source: NIH National Heart, Lung, and Blood Institute / Kaggle
   - Features: Age, Gender, sysBP, diaBP, totChol, Glucose, BMI, Heart Rate, Smoking, Hypertension, Diabetes, 10-Yr CHD

2. UCI Heart Disease Dataset (heart.csv)
   - Record Count: 1,025 patient records
   - Source: UCI Machine Learning Repository (Cleveland, Hungarian, Switzerland, VA Long Beach)
   - Features: Age, Sex, Resting BP, Cholesterol, Fasting Blood Sugar, Max Heart Rate, Angina, ST Depression, Target

3. Cardiovascular Disease Dataset (cardio_train.csv)
   - Record Count: 70,000 patient records
   - Source: Kaggle Cardiovascular Disease Dataset
   - Features: Age, Gender, Height, Weight, Systolic BP, Diastolic BP, Cholesterol, Glucose, Smoking, Alcohol, Target

4. MIMIC-IV Clinical Database Demo v2.2 (mimic-iv-clinical-database-demo-2.2)
   - Source: PhysioNet / MIT Laboratory for Computational Physiology
   - Features: ICU admissions, lab telemetry, vitals events, ICD-9/10 diagnostic codes

DATA VOLUME AND FEATURE SUMMARY:
---------------------------------------------------------------------------------------------------------------------
- Master Training Cohort Volume: 4,683 Clean Combined Clinical Records (Extensible to 75,266 records)
- Number of Clinical Features Per Record: 16 Features
  1. Age
  2. Gender
  3. Systolic BP
  4. Diastolic BP
  5. Body Mass Index (BMI)
  6. Heart Rate
  7. Glucose Level
  8. Total Cholesterol
  9. Essential Hypertension Flag
  10. Type 2 Diabetes Mellitus Flag
  11. Active Tobacco Smoking History
  12. Previous Cardiac Event / Stroke History
  13. Pulse Pressure (Derived: Systolic BP - Diastolic BP)
  14. Mean Arterial Pressure (Derived: Diastolic BP + Pulse Pressure / 3)
  15. Glucose-to-BMI Ratio (Derived)
  16. Weighted Comorbidity Burden Index (Derived)

- Total Data Points Processed in Training: 4,683 records x 16 features = 74,928 Clinical Data Points
- Primary Production Model: CatBoost Classifier (Version 9) with Isotonic Calibration
- Evaluation Date: 2026-07-27
